# Timbre

A single-file, offline gallery of synthesized sound effects. Every sound is a small WebAudio recipe
(oscillators, seeded noise, filters, envelopes, waveshapers, delays and generated reverbs): no
samples, no downloads, no dependencies. Timbre is the audio sibling of Prism, the CSS/SVG component
gallery.

- **Browse and audition**: one card per sound with a waveform rendered offline, its duration, peak
  and RMS, live parameter sliders, and a Vary switch that draws a new noise seed per play.
- **Copy** gives one self-contained JavaScript function per sound, carrying only the helpers it
  uses. Pasted anywhere, it renders the same as the gallery (the copy gate checks this to 0.5 dB).
- **Save WAV** renders offline to 16-bit PCM at 48 kHz.
- **Sound themes** map app moments (click, toggle-on, success, error, ...) to sounds, so a whole set
  can be swapped at once. The first theme is Soft UI.
- **Measured levels**: every sound is rendered through the same master chain (gain, a limiter, a
  ceiling) and gated to the house range, at its defaults and at random settings.

## Open it
Open `dist/timbre.html` in a browser. It works from disk, offline; nothing is fetched. Sound starts
on your first click (browsers require a gesture). Press `/` to search.

## Use a copied sound
```js
// Usage: const ac = new AudioContext(); uiClickSoft(ac, { pitch: 1100 }); ...
function uiClickSoft(ac, opts, when, dest) { /* helpers + the recipe, generated by Copy */ }

const ac = new AudioContext();
button.addEventListener('click', () => uiClickSoft(ac));
```
`opts` overrides the parameter values baked in at copy time (and `seed`), `when` is the earliest
start time, `dest` an optional node to end in. The function returns the time the sound ends. The
first call on a context builds the master chain and starts the sound 0.2 s later, while the limiter
warms up; later calls play at once.

## Add a sound in three steps
1. Write `src/sounds/<category>/<id>.js`: id, name, category, tags, desc, dur, params and a
   `play(T, out, t, p)` that uses the helper kit `T`. Start from a seed sound in the same category.
2. Run `node build.mjs`. It validates every sound (fields, parameter ranges, `play` run in isolation
   at the defaults, the extremes and random settings) and rebuilds `dist/timbre.html` and the
   catalog.
3. Run the gates (below), tune peaks until the level gate passes, then listen in the page.

The full contract, the helper API and the level targets are in
[docs/ADDING_SOUNDS.md](docs/ADDING_SOUNDS.md); the design is in [docs/DESIGN.md](docs/DESIGN.md).

## Run the gates
```
node build.mjs --check          # sources valid, dist/ and catalog/ up to date
node --test gates/*.test.mjs    # unit tests: build validation, Copy tree-shaking, core helpers, WAV
node gates/check_levels.mjs     # every sound, 12 renders each, against the house level range
node gates/check_page.mjs       # the page: cards, Play, keyboard, filters, theme, WAV, Copy, phone width
node gates/check_copy.mjs       # each Copy pasted into a blank page matches the gallery within 0.5 dB
bash gates/run_all.sh           # all of the above, browser gates one at a time
```
The browser gates need Edge or Chrome (set `TIMBRE_BROWSER` to use another Chromium-family
binary). Each launches one headless browser with muted audio and kills its whole process tree when
done. On a machine where browser jobs must queue, set `TIMBRE_BROWSER_WRAP` to the queue command
prefix and `run_all.sh` runs each browser gate through it. Screenshots and `levels.json` land in
`gates/out/`. Node 22, no dependencies.

## Layout
```
src/core/          synth library (T): seeded noise, envelopes, voices, effects, master chain;
                   offline render and measurement, WAV encoder, Copy builder
src/sounds/<category>/<id>.js   one sound per file
src/themes/<id>.js              sound themes: moment -> sound + parameter overrides
src/shell/         the gallery page: index.html template, style.css, app.js
build.mjs          validates, writes catalog/manifest.json and catalog/index.json, bundles dist/timbre.html
catalog/           manifest.json (every field, play source, helper list, helper sources); index.json (search fields)
dist/timbre.html   the single page (generated; do not edit by hand)
gates/             unit tests and the level, page and copy gates
```
